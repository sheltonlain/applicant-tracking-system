Where did this candidate come from?

The question: Candidates reach us through the company website, job boards, referrals and other channels. Should the system save that as (A) a fixed list of choices plus an optional note, (B) a list of sources that staff can add to themselves, or (C) whatever the staff member types? And should the source be saved once per candidate or separately for each job application? Each button below runs the same real-world event through every option side by side, so you can see what each one would actually keep. (The rule we already settled still applies: every candidate needs a unique email.)
